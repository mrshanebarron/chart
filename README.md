# Laravel Design Chart

Chart component using Chart.js for Laravel. Supports Livewire, Blade, and Vue 3.

## Installation

```bash
composer require mrshanebarron/chart
```

## Usage

### Livewire Component

```blade
<livewire:ld-chart />
```

### Blade Component

```blade
<x-ld-chart />
```

## Configuration

Publish the config file:

```bash
php artisan vendor:publish --tag=ld-chart-config
```

## Customization

### Publishing Views

```bash
php artisan vendor:publish --tag=ld-chart-views
```
